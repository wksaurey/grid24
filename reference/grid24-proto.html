Gestures
tap = letter · hold = small letter / digit · tap text = place cursor · double-space = period
quick swipe ⇠ ⇢ = move cursor (with selection: jump to that end)
slow drag ⇠ = select back · slow drag ⇢ = select forward / move selection
swipe ↑ = shift · swipe ↓ left = symbols · ↓ right = calculator · ↓ in a layer = back
hold SPACE = enter · hold DELETE = repeat
edit button: tap one key, then another — they swap (per layer, saved on device)
